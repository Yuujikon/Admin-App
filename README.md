# GDC Sari-Sari Store - Admin App 🚀

A robust management and POS system for the GDC family business.

## 🛠 Features
- **Dashboard**: Real-time sales tracking, expense management, and top-selling product insights.
- **POS (Point of Sale)**: Fast barcode scanning (camera & physical hardware) with stock restrictions.
- **Inventory**: Complete product management with category filtering and low-stock warnings.
- **Order Management**: Live tracking of customer pre-orders with multi-stage status updates (Packing -> Ready -> Collected).
- **Security**: Double-layer security with a 4-digit PIN and official Firebase Email Authentication.
- **Store Status**: Manual and scheduled store closure logic with automatic customer notifications.

## 📱 Tech Stack
- **Framework**: Flutter
- **Database**: Cloud Firestore (Real-time streams)
- **Auth**: Firebase Authentication
- **State Management**: Provider
